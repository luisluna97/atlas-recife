## Limites

- Protótipos privados, com `noindex`; não autorizam publicação ou contato.
- Termos de busca são hipóteses a validar, não dados de volume ou promessa de
  posicionamento.
- O material preserva fatos úteis observados, mas não substitui inventário e
  validação com cada organização antes de migração.
- Método de seleção: `04-intelligence/transformation-priority-method-v0.md`.
- Executor: Codex; linguagem pública revisada pelo gate
  `atlas-public-language`; versão dos entregáveis: v1.
