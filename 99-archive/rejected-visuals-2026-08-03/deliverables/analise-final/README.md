## Como visualizar

No Explorador de Arquivos, abra esta pasta e dê dois cliques no `index.html` do
site desejado. Os PDFs abrem normalmente no leitor padrão. O arquivo
`ABRIR-ENTREGAVEIS.html` também funciona como menu local.
