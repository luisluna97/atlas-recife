# Convenções técnicas

- Parsing, validação, normalização, hashing e persistência são código testável.
- Uso de modelo registra provedor, modelo, parâmetros, contrato, tokens e custo.
- JSON Schema Draft 2020-12 é o formato inicial de contratos.
- Versionamento semântico é provisório e requer ADR definitivo.
- Eventos operacionais usam UTC ISO 8601.
- Segredos ficam fora do Git.
- Dados privados de clientes ficam isolados de prospecção pública.
