# Registro de conversas

Preserva contexto importante independentemente do chat ou da máquina.

## Política

- Registrar resumo fiel, não transcrição automática integral.
- Preservar objetivos, decisões, dúvidas e próximos passos.
- Não copiar segredos ou dados pessoais desnecessários.
- Decisão formal continua em `DECISIONS.md` ou ADR.
- Implementação continua no Git e no diário.
- Distinguir confirmação do fundador de proposta do agente.
