# Como navegar no War Room pelo Obsidian

## Começo recomendado

Abra `HOME.md`. Ele é o mapa executivo e leva às áreas centrais.

## Graph View

O grafo global mostra todas as notas:

- círculo: uma nota;
- linha: um link entre notas;
- círculo maior: nota mais conectada;
- grupo próximo: documentos que se referenciam.

Use o grafo global para explorar a organização geral, não para acompanhar
trabalho diário.

## Local Graph

Abra uma nota, acione a paleta com `Ctrl+P` e procure **Open local graph**.
Ele mostra a nota atual, seus links e backlinks. É a melhor maneira de entender
o que se conecta a um assunto específico.

## Backlinks

Backlinks mostram quais notas apontam para a nota atual. Abra a barra lateral de
backlinks para descobrir onde uma ideia é usada.

## Caminhos úteis

- CEO e operação: `00-war-room/maestro/README.md`
- trabalho corrente: `00-war-room/missions/README.md`
- visão geral: `HOME.md`
- decisões: `DECISIONS.md`
- dados: `03-data/README.md`
- agentes: `05-agents/README.md`
- pesquisa: `06-research/README.md`

## Regra de organização

Pastas dizem onde a nota pertence. Links dizem com que ela se relaciona. O grafo
só fica útil quando os documentos possuem links intencionais; quantidade de
notas sem relações produz apenas ruído.
