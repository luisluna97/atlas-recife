# Catálogo de fontes — estrutura

Nenhuma fonte está aprovada para coleta nesta versão. Este documento define como
avaliá-las.

## Campos

- ID e nome;
- operador;
- tipo de acesso;
- entidades e variáveis oferecidas;
- cobertura geográfica;
- custo;
- estabilidade;
- frequência permitida;
- termos e políticas;
- base legal e finalidade;
- dados pessoais envolvidos;
- limites técnicos;
- evidência preservável;
- qualidade esperada;
- alternativas;
- decisão: ignorar, monitorar, experimentar ou aprovar.

## Famílias candidatas

- sites oficiais das empresas;
- dados abertos governamentais;
- diretórios e listings;
- mecanismos de busca;
- redes sociais;
- provedores de tecnologia e performance;
- observação manual;
- dados privados de clientes com autorização.

Cada família passará por pesquisa e revisão de compliance antes de experimento.
