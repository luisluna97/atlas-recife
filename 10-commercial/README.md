# Comercial

Não há prospecção autorizada nesta fase. Pacote, preço, canal, cadência, CRM e
política detalhada permanecem abertos.

O momento zero comercial depende dos critérios do `ATLAS.md`.

## Tese comercial aprovada

O Atlas não vende apenas um site bonito. Vende o site como porta de entrada de um
sistema mensurável:

`ser encontrado → gerar confiança → facilitar contato → acompanhar → aprender`

Camadas possíveis: estratégia, site/landing, SEO, conteúdo, mídia, analytics,
CRM, automações e otimização contínua. Resultado comercial é hipótese medida,
não promessa. Referência: [[../06-research/website-as-growth-system-v0]].
