# Como contribuir

1. Leia `ATLAS.md`, `DECISIONS.md` e `AGENTS.md`.
2. Não introduza ferramenta sem problema concreto do Atlas.
3. Rotule hipóteses e inferências.
4. Preserve proveniência e histórico.
5. Prefira código testável para tarefas determinísticas.
6. Registre modelo, custo e evidências quando usar LLM.
7. Nunca versione segredos.
8. Use links relativos compatíveis com GitHub e Obsidian.
9. Datas humanas usam `YYYY-MM-DD`; eventos futuros usam UTC.
10. Atualize decisões e diário quando arquitetura ou visão mudarem.
