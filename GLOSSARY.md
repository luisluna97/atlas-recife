# Glossário

**Agente:** função operacional versionada com missão, entradas, saídas,
ferramentas, limites, KPIs, evidências e auditoria.

**Dado observado:** fato capturado diretamente, com fonte, método e tempo.

**Dado inferido:** interpretação probabilística rotulada como tal.

**Dado derivado:** valor calculado de forma reproduzível.

**Evidência:** artefato que sustenta observação ou decisão.

**Job:** unidade executável e retomável criada a partir de uma missão.

**Laboratório:** sistema que testa ferramentas, fontes, métodos e hipóteses.

**Momento zero comercial:** prospecção autorizada após os critérios do Atlas.

**Observação:** registro temporal com valor, classe e proveniência.

**Observatório Recife:** sistema contínuo de inteligência sobre empresas locais.

**Proveniência:** origem, tempo, método, executor, versão e evidência.

**Score:** instrumento versionado e explicável; não é verdade absoluta.

**War Room:** GitHub aberto como Vault no Obsidian, complementado no futuro pelo
Supabase operacional.
